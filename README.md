# 🚀 Career Tracker

### Your Career, Your Goals, Your Progress!

## 📌 About the Project

Career Tracker is a student-friendly web application designed to help students organize their career goals, learn technical skills, follow a learning roadmap, and prepare for placements.

The project provides a simple interface to organize career preparation in one place.

## 🌐 Live Demo

🔗 [Visit Career Tracker Website](file:///C:/Users/deeks/Projects/Career-Tracker/index.html)

## ✨ Features

- 🏠 Dashboard to view career preparation details.
- 🎯 Career goals to organize learning objectives.
- 💻 Skills section to track technical skills.
- 🗺️ Learning roadmap to plan skill development.
- 📈 Progress section to monitor learning progress.
- 🎨 Clean and attractive user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
